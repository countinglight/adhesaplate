# Developer script reference

Run commands from the repository root after `npm ci`. Build and deployment are documented in
[BUILD.md](../BUILD.md). Add an entry here whenever a utility is added to this directory.

| Script                                               | Command / caller                                                        | Purpose and effects                                                                                                                                                                                                     |
| ---------------------------------------------------- | ----------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [check-line-endings.js](check-line-endings.js)       | `npm run line-endings:check`; part of `npm run check`                   | Checks tracked text files for CRLF; exits nonzero on violations without changing files.                                                                                                                                 |
| [mark-review-headers.js](mark-review-headers.js)     | `node scripts/mark-review-headers.js`; last step of `npm run build:site` | Appends an `X-Robots-Tag: noindex` rule to `website/dist/_headers` unless a route in `wrangler.site.jsonc` is the production hostname. Requires an existing build. Does not deploy. See [Search engines](../BUILD.md#search-engines). |
| [lighthouse-check.js](lighthouse-check.js)           | `npm run lighthouse` (after a build); `node scripts/lighthouse-check.js --runs=1` | Serves `website/dist` locally and scores four pages with Lighthouse in mobile mode using the machine's Chrome, headless. Exits nonzero below budget. Writes reports to `lighthouse-reports/`; uploads nothing. See [Page speed](../BUILD.md#page-speed). |
| [mark-bluehost-staging-noindex.js](mark-bluehost-staging-noindex.js) | Bluehost staging GitHub workflow after `npm run build -w website` | Adds a noindex meta tag to every generated HTML page because Apache does not use Cloudflare's `_headers` file. Does not deploy. |
| [bluehost-production-manifest.mjs](bluehost-production-manifest.mjs) | Manual Bluehost production workflow after Astro build | Validates production HTML and generated paths; emits the sorted list of files the release may own. Does not deploy. |
| [bluehost-production-remote.sh](bluehost-production-remote.sh) | Manual Bluehost production workflow over SSH | Read-only `plan`, guarded `prepare`, and backed-up `activate` steps. Refuses root WordPress and unmanaged file collisions. |
| [test-bluehost-production-release.sh](test-bluehost-production-release.sh) | `bash scripts/test-bluehost-production-release.sh` | Exercises plan, WordPress guard, activation, protected `/dev`, stale managed-file removal, and unmanaged-file collision in a temporary fake document root; never connects to Bluehost. |
